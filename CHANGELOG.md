# Changelog

## 1.0.0 — 2026-10-07

- Clarify that the app creates WhatsApp chat links and cannot verify account registration.
- Replace unsafe HTML interpolation with validated, fixed-origin link construction.
- Accept common international phone formatting and reject malformed input.
- Add a responsive interface, keyboard submission, accessible feedback, and stale-result clearing.
- Expand usage, privacy, development, deployment, and contribution documentation.
- Add a source audit, security guidance, and automated regression checks.
- Preserve the original GPL-3.0 license and dependency-free architecture.
